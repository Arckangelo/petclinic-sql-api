## owners

A tabela guarda os dados dos donos dos pets.

### Colunas

Legenda: **Nulo? Sim** = a coluna aceita ficar vazia; **Não** = preenchimento obrigatório.

| Colunas | Tipo | Nulo? | Padrão | Descrição|
|:---|:---|:---:|:---|:---|
| `id`| `integer` | Não | `generated by default as identity`| Identificador único (PK) |
| `first_name` | `text` | Sim | — | Primeiro nome |
| `last_name` | `text` | Sim | — | Sobrenome |
| `address` | `text` | Sim | — | Endereço |
| `city` | `text` | Sim | — | Cidade |
| `telephone` | `varchar(10)` | Não | — | Telefone |

### Índices

| Nome | Tipo | Colunas | Observações |
|:---|:---|:---|:---|
| `owners_pkey` | PRIMARY KEY | `id`| Chave primária |
| `owners_last_name_idx`| btree | `last_name`| Busca por sobrenome |

### Relacionamentos

Um dono pode ter vários pets, e cada pet tem um único dono (`pets.owner_id → owners.id`).

```
TABLE "pets" ... FOREIGN KEY (owner_id) REFERENCES owners(id)
```

### Fora do banco

Regras que o banco **não** garante e que ficam por conta da aplicação.
Testado no banco do ambiente (docker compose), dentro de uma transação desfeita com `ROLLBACK`.

| Situação | O banco... | Evidência |
|:---|:---:|:---|
| Dono só com telefone, sem nome nem sobrenome | aceita | `INSERT INTO owners (telephone) VALUES ('6085551023');` → `INSERT 0 1` |
| Telefone com letras | aceita | `INSERT INTO owners (telephone) VALUES ('abc');` → `INSERT 0 1` |
| Telefone com menos de 10 caracteres | aceita | `INSERT INTO owners (telephone) VALUES ('608555102');` → `INSERT 0 1` |
| Nome só com espaços | aceita | `INSERT INTO owners (first_name, telephone) VALUES ('   ', '6085551023');` → `INSERT 0 1` |
| Telefone vazio (`''`), mesmo com `NOT NULL` | aceita | `INSERT INTO owners (telephone) VALUES ('');` → `INSERT 0 1` |
| Telefone com 11 dígitos | **recusa** | `INSERT INTO owners (telephone) VALUES ('11987654321');` → `ERROR: value too long for type character varying(10)` |

O `varchar(10)` só limita o tamanho máximo. Por isso um celular brasileiro
com DDD (11 dígitos) é recusado, enquanto `'abc'` e `'608555102'` passam.
